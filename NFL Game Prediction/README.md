Predicting NFL game outcomes (win/loss) using machine learning on 11,894 games from 2003-2024 seasons. Implements temporal feature engineering that blends previous-season statistics with expanding current-season averages using exponential decay. Created 71 features including team stats, opponent stats, and differential features that capture relative matchup advantage. Tested Logistic Regression, Random Forest, and K-Nearest Neighbors using 10-fold cross-validation. Results: Logistic Regression achieves 63.87% accuracy, significantly outperforming Random Forest (60.45%) and KNN (56.63%), representing a 28% improvement over baseline. Key finding: differential features dominate predictions, and simple linear models excel when features are well-engineered.
